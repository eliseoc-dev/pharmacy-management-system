# Pharmacy Management System — Project Specification

## Purpose

Build a modern full-stack pharmacy management application.

The project demonstrates:

- Python
- FastAPI
- REST APIs
- React
- TypeScript
- MySQL
- SQL
- CRUD
- Validation
- Testing
- Frontend/backend integration
- Git and GitHub

---

## Version 1 Features

### Products

Each product contains:

- ID
- Name
- Description
- Price
- Stock
- Minimum stock
- Category
- Supplier
- Expiration date
- Created date

### Product Operations

Users can:

- Create products
- View products
- Update products
- Delete products
- Search products
- Filter products
- View low-stock products

---

## Categories

Users can:

- Create categories
- View categories
- Update categories
- Delete categories

Examples:

- Analgesics
- Antibiotics
- Vitamins
- Personal care

---

## Suppliers

Users can:

- Register suppliers
- View suppliers
- Update suppliers
- Delete suppliers

Supplier information:

- Name
- Contact name
- Email
- Phone

---

## Inventory

The application must track:

- Current stock
- Minimum stock
- Low-stock products
- Product expiration dates

---

## Architecture

Frontend:

React + TypeScript

Backend:

FastAPI + Python

Database:

MySQL

Communication:

REST API using JSON
