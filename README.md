# Pharmacy Management System

Full-stack pharmacy inventory and management application.

## Technologies

### Backend
- Python
- FastAPI
- MySQL

### Frontend
- React
- TypeScript
- Vite

### Development
- Git
- GitHub
- pytest

## Project Goals

The system will allow users to manage:

- Products
- Categories
- Inventory
- Stock
- Suppliers
- Product searches
- Low-stock alerts

Additional features will be added as the project evolves.
